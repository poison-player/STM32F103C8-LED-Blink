# STM32F103C8 LED Blink

## Project Overview
This project demonstrates LED blinking using the STM32F103C8 microcontroller and STM32 HAL library.

## Software
- STM32CubeIDE
- STM32 HAL Library
- Embedded C

## Working
GPIOB Pin 0 is configured as a digital output. The LED is turned ON for 1 second and OFF for 1 second continuously.

## Code
The main application code is available in:
`Core/Src/main.c`

## Key Concepts
- GPIO configuration
- GPIOB Pin 0
- HAL GPIO functions
- HAL_Delay()
- Embedded C
